# Read It Later

A local-first Flutter Android read-it-later app.

The first version stores extracted article content on the device and renders it
in a clean reading view without requiring an account or a server.

The Android application ID is `com.heraklysia.read_it_later`.

## Development Environment

- Flutter 3.47.1 stable
- Dart 3.13.1
- Android SDK Platform 36
- Android SDK Build-Tools 36.0.0
- Android NDK 28.2.13676358
- Android Studio bundled JDK

The debug APK has been buildable on the local Android emulator. Android
Command-line Tools 23 deprecates the old `sdkmanager --licenses` entry, so
Flutter Doctor may still report an unknown license status even though Android
builds accept the installed SDK licenses.

## Common Commands

```powershell
flutter pub get
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --debug
flutter run -d emulator-5554
```

`android/local.properties` is generated by Flutter or Android Studio and
contains machine-specific paths. It must not be committed.

## Directory Conventions

- `lib/`: application source code
- `test/`: automated tests
- `work/`: local research and experiments excluded from analysis and builds
- `DEVELOPMENT_PLAN.md`: product scope, architecture, and implementation plan
